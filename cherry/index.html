VS Code

            
Theme extension

            
    
              
  1. Download washed-away-cherry-theme-1.0.1.vsix.
    2. 
              
  2. In VS Code, open Extensions, choose Views and More Actions..., then Install from VSIX....
    3. 
              
  3. Select the file, then choose Washed Away Cherry from Color Theme.
    4.

    3.
